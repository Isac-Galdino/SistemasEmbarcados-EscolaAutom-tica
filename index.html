SOBRE O PROJETO

Uma escola mais tecnológica

O projeto demonstra como conhecimentos de Desenvolvimento de Sistemas podem ser aplicados em um projeto físico de automação.

💡 Como nasceu a ideia?

A ideia surgiu a partir da necessidade de pensar em uma forma tecnológica de organizar processos dentro do ambiente escolar.

Problema → Tecnologia → Solução
O projeto transforma uma necessidade em uma experiência prática de robótica.

FAQ

Perguntas frequentes

O que é a Escola Automática?

É um projeto de robótica que utiliza programação e componentes eletrônicos para criar um sistema automatizado aplicado ao ambiente escolar.

Qual é o principal controlador?

O Arduino é utilizado como unidade responsável pelo processamento e controle dos componentes.

Para que serve o sensor?

O sensor permite que o sistema detecte uma determinada condição e envie essa informação para o Arduino.

Qual é a função do servo motor?

O servo motor executa movimentos controlados de acordo com a programação do sistema.
